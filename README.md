# Heap
Данный проект реализует структуру данных в виде макси-кучи, со всеми его составляющими
Бинарная макси-куча на массиве: в корне максимальный элемент.

Поля
heap — массив элементов
size — текущий размер
capacity — вместимость

Методы
MaxHeap(int capacity) — создаёт пустую кучу.
parent(i), leftChild(i), rightChild(i) — индексы родителя и детей.
swap(i, j) — меняет два элемента местами.
insert(value) — вставляет элемент и просеивает вверх. O(log n).
extractMax() — возвращает максимум, переносит последний элемент в корень и просеивает вниз. O(log n).
placeHeapRoot(i) — просеивание вверх.
placeHeapBottom(i) — просеивание вниз.
printTree() — выводит кучу в виде дерева.
main(...) — демонстрация работы.

Исключения
"Куча заполнена" — при вставке в полную кучу.
"Куча пуста" — при извлечении из пустой кучи.
